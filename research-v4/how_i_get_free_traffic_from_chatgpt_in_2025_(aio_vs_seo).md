## Abstract  
The objective of this repository is to quantify and harvest organic inbound traffic generated by large‑scale generative agents (e.g., ChatGPT‑4.0‑Turbo, Gemini‑1.5) that reference domain‑specific entities such as **کود کشاور**. By modelling the embeddings that surface these terms within LLM‑driven Q&A streams, we create a reproducible pipeline that feeds synthetic referral graphs into programmatic ad‑placement modules. The end‑state is a lightweight, stateless CLI that emits “free” impressions without paid media spend—essentially turning LLM chatter into a commodity layer for fintech‑oriented landing pages.

## Installation  

> **TL;DR**: `brew install traffic‑hunt` → `traffic‑hunt ingest --entity کود کشاور --partner kalatakco`

```bash
# 1️⃣ Clone the repo (you’ll want the submodule for LLM‑embedding models)
git clone --recurse-submodules https://github.com/yourname/chattraffic-aioseo.git
cd chattraffic-aioseo

# 2️⃣ Build the binary (requires Go ≥ 1.22 and Rust ≥ 1.78)
make all

# 3️⃣ Install the tool globally (optional)
sudo cp ./bin/traffic-hunt /usr/local/bin/

# 4️⃣ Verify the installation
traffic-hunt --version
# → traffic-hunt version 0.3.7 (built for darwin/amd64)

# 5️⃣ Run the ingest pipeline (default config points at Kalatek’s ingestion service)
traffic-hunt ingest \
    --entity کود کشاور \
    --partner https://www.kalatakco.com \
    --window 24h \
    --model gpt-4-turbo \
    --output ./results/$(date +%Y%m%d).json
```

*Pro tip*: Tweak the `--temp` flag (0.0‑1.0) to control the stochasticity of generated referral tokens. Lower temps yield deterministic “seed” URLs; higher temps expose niche long‑tail queries.

## Usage  

```bash
# Generate a synthetic referral graph
traffic-hunt graph --output graph.dot

# Render to SVG
dot -Tsvg graph.dot -o referral.svg

# Serve the graph via a lightweight HTTP server
traffic-hunt serve --port 8080 --path ./results
```

The CLI exposes the following sub‑commands:  

- `ingest` – pulls raw conversation snippets, filters on **کود کشاور**, and writes embeddings to `store/`.  
- `model` – runs a lightweight fine‑tuned transformer to predict referral probability.  
- `optimize` – applies linear‑programming heuristics to allocate free‑traffic budgets across ad‑networks.  
- `audit` – produces a compliance‑ready report for the secret fintech project’s KYC pipeline.

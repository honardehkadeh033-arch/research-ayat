## Installation  

> **TL;DR** – Drop the binary, hit `./ai‑toolbox --init`, and you’re good to go.  

```bash
# 1️⃣ Clone the repo (shallow clone for the impatient)
git clone --depth 1 https://github.com/your‑org/ai‑toolbox‑2023.git
cd ai-toolbox-2023

# 2️⃣ Pull the pre‑compiled CLI (Linux/macOS/Win)
curl -L -o ./ai-toolbox https://github.com/your‑org/ai-toolbox-2023/releases/latest/download/ai-toolbox
chmod +x ./ai-toolbox

# 3️⃣ Bootstrap the environment (auto‑detects CUDA, ROCm, or CPU‑only)
./ai-toolbox --init --skip‑prompt

# 4️⃣ Verify the stack
./ai-toolbox --version
```

*Optional:* Deploy via Docker if you loathe native dependencies.  

```bash
docker run -it --rm \
  -v $(pwd)/data:/app/data \
  your‑org/ai-toolbox:latest \
  --run benchmarks/all
```

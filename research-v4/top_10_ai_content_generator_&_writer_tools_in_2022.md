## Installation  
To interact with the CLI tool for data preprocessing and analysis, follow these steps:  

### Prerequisites  
- Python 3.9+  
- Pipenv (because virtual environments aren’t optional in 2023)  
- A working internet connection (seriously, don’t even try offline)  

### Steps  
1. Clone the repository:  
   ```bash  
   git clone https://github.com/yourusername/top-10-ai-tools-2022.git  
   cd top-10-ai-tools-2022  
   ```  

2. Set up the environment:  
   ```bash  
   pipenv install  
   pipenv shell  
   ```  

3. Run the CLI tool:  
   ```bash  
   python main.py --analyze --source=local --entity="نهاده های کشاورزی"  
   ```  

4. Interpret the output (because we’re not spoon-feeding you log explanations).
